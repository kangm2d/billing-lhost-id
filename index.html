IP Host: Memuat...
1. PC Windows (Server Utama)

Jalankan file ini di PC server. Komputer lain atau HP Android dapat membuka browser dan mengetik alamat IP LAN komputer.

2. Folder Backup Bersama

Simpan file kasir-wifi.html di folder sharing Windows (Network Share) agar bisa diakses bersama.

3. HP Android (Kasir Loket)

Hubungkan HP ke WiFi yang sama dengan PC server, lalu masukkan IP LAN di browser HP untuk mencetak struk langsung.

Panduan Akses Satu Jaringan (LAN):

Pastikan PC & HP terhubung ke router WiFi yang sama. Di HP Android, buka Chrome dan ketik alamat IP lokal PC (contoh: http://192.168.1.100:8000/kasir-wifi.html).
